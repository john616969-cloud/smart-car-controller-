# 智能车蓝牙网页控制器

这个网页通过 JDY 蓝牙模块的 `FFE0/FFE1` 服务控制 STM32F103C8T6 智能车，可发送循迹、倒车、停车、传感器开关、避障开关和调速命令，并支持14项运行参数实时调节、7档手动电压 PID、十字路口弱 PD、设备记忆与自动重连、历史曲线滑动和数据导出。

蓝牙区下方有“控制、传感、调参、反馈”四个页面入口；紧急停车固定在入口上方，切换到任何页面都可以立即使用。

## 一、电脑上预览

推荐使用 Chrome 或 Edge。

1. 打开命令提示符或 PowerShell。
2. 进入 `web-controller` 文件夹。
3. 如果电脑装有 Python，运行：

   ```text
   python -m http.server 8000
   ```

4. 浏览器打开 `http://localhost:8000`。
5. 点击“选择蓝牙设备”，在浏览器设备列表中选择 JDY 模块。

如果电脑没有蓝牙，只能预览界面，不能连接小车。

## 二、部署成苹果手机可打开的网址

苹果手机需要通过 HTTPS 地址打开网页。最简单的免费方式是 GitHub Pages：

1. 注册并登录 GitHub。
2. 新建一个公开仓库，例如 `smart-car-controller`。
3. 把本文件夹中的 `index.html`、`styles.css`、`app.js` 上传到仓库根目录。
4. 打开仓库的 `Settings` → `Pages`。
5. 在 `Build and deployment` 中选择 `Deploy from a branch`。
6. 分支选择 `main`，目录选择 `/ (root)`，然后保存。
7. 等待一两分钟，GitHub 会给出一个 `https://...github.io/...` 地址。

## 三、苹果手机连接小车

普通 Safari 不能直接使用这个网页的蓝牙功能。

1. 在 App Store 安装 **Bluefy – Web BLE Browser**。
2. 打开手机蓝牙，并给 Bluefy 蓝牙权限。
3. 在 Bluefy 中输入上一步得到的 HTTPS 网页地址。
4. 给 JDY 模块和小车上电，确保模块未被其他手机连接。
5. 点击网页中的“选择蓝牙设备”。
6. 在系统蓝牙窗口中选择 JDY 模块。
7. 页面显示“已连接”后即可控制。

不要先在 iPhone 系统“设置 → 蓝牙”中配对。BLE 模块应当由网页中的“选择蓝牙设备”按钮连接。

## 四、控制命令

| 网页功能 | 发送内容 |
| --- | --- |
| 开始循迹 | `!F` |
| 倒车 | `!B` |
| 紧急停车 | `!S` |
| 接入传感器 | `!T` |
| 关闭传感器 | `!N` |
| 开启自动避障 | `!O` |
| 关闭自动避障 | `!X` |
| 开启十字路口检测 | `!Q` |
| 关闭十字路口检测 | `!C` |
| 10%～90%速度 | `!1`～`!9` |

小车开机默认开启自动避障。发送 `!X` 后，HC-SR04 仍继续测距，OLED 和网页仍显示距离，但距离不会再让小车自动减速或停车。网页会自动添加 `!`；使用普通蓝牙调试助手时需要手动发送完整命令。

十字路口检测也默认开启。发送 `!C` 只关闭十字路口状态机，正常 PD 循迹、超声波避障和传感器数据采集继续运行；发送 `!Q` 可重新开启。

## 五、偏差表盘与曲线导出

- “左右偏差表盘”使用 STM32 返回的 `ERROR` 数据，负值指向左侧，正值指向右侧。
- “传感器变化曲线”显示最近60秒的 L1、L2、R1、R2，可点击顶部标签隐藏或显示某一路。
- 在曲线上用手指左右滑动，可查看最近30分钟的历史；点击“回到实时”恢复自动跟随。
- “暂停”只暂停画面滚动，蓝牙数据仍继续保存；再次点击“继续”恢复最新画面。
- “清空”只清除网页中的历史记录，不影响小车。
- “导出 CSV”保存最近最多30分钟的原始数据，可用 Excel 打开。
- “曲线图片”会先打开真实图片预览。在苹果手机 Bluefy 中长按图片即可保存到照片，也可以尝试系统分享；电脑仍可下载 PNG。
- “生成调试报告”会把当前状态、最近30分钟传感器数据和最近80条通信日志合并成 TXT，可复制、分享或下载后发送给 Codex 分析。

## 六、手机实时调参

- 连接成功后网页自动发送 `@GET PARAMS`，读取芯片当前的14个运行参数。
- 调参页可手动选择 `8.1V～7.5V`；芯片按“电压档 + 速度档”使用独立循迹 PID，共63组，初始值均复制当前九档默认表。
- 电压协议使用十分之一伏整数，例如 `@SET VOLTAGE_LEVEL 81` 表示选择8.1V。
- 每项参数可直接输入，也可以用 `－/＋` 按规定步长调整，再点击单项“应用”或“应用全部”。
- STM32 校验参数范围和相互关系，网页收到 `PARAM ... OK` 后才显示“已生效”。
- “导出参数”会生成 TXT，包含芯片确认的参数、当前传感器数据和十字路口状态。
- 参数只保存在 RAM；芯片复位或重新上电后恢复 `main.c` 中的默认值。
- 文本协议使用 `@SET 参数名 数值` 和 `@GET PARAMS`；车辆控制必须带 `!` 帧头，防止调试回显误触发停车或关闭传感器。

## 七、上次设备与自动重连

- 首次选择并成功连接后，网页在本机记录设备名称和浏览器设备 ID。
- 再次打开网页时会自动尝试连接上次获准访问的设备。
- 浏览器不支持恢复权限时，使用“重连上次设备”或“选择蓝牙设备”。
- 异常断线后每隔约2秒重试，最多3次；主动点击“断开”不会自动重连。
- 只有真正完成 FFE0/FFE1 连接后，控制按钮和紧急停车才会启用。

## 八、常见问题

- 搜不到模块：检查模块供电、手机蓝牙权限，以及模块是否已连接另一台设备。
- 能连接但无数据显示：确认 STM32 TX/RX 与模块交叉连接，并确认 JDY-31 已通过 `AT+BAUD7` 设置为 57600；网页连接后等待 FFE1 通知。
- 按钮无反应：查看页面底部通信日志。出现 `TX` 表示网页已尝试发送；出现 `ERR` 时按错误提示检查。
- 页面提示不支持网页蓝牙：苹果手机必须使用 Bluefy；电脑使用最新版 Chrome 或 Edge。
- 连接后立即断开：先关闭其他蓝牙调试助手，再给 JDY 模块重新上电后连接。
