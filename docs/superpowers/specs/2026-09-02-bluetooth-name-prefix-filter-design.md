# 蓝牙设备名称包含过滤设计

## 目标

网页的设备选择只显示名称以 `JDY` 开头的设备，记忆设备和自动重连允许名称中包含 `JDY` 的设备，减少在多人、多车环境中误选其他模块的概率，同时兼容不同型号的 JDY 模块。

## 方案

- `requestDevice()` 使用前缀过滤 `namePrefix: "JDY"`。Web Bluetooth 原生选择器不支持任意位置的包含过滤，前缀过滤可覆盖常见的 `JDY-xx` 名称并保持列表整洁。
- 连接入口统一使用不区分大小写的包含校验；设备名称中含有 `JDY` 才允许继续连接。
- FFE0 作为 `optionalServices` 授权，并在连接后继续验证服务和 FFE1 特征。
- 不在选择过滤器中强制要求设备广播 FFE0，避免兼容性较差的模块从列表中消失。
- 已记住设备的名称不包含 `JDY` 时不显示“重连上次设备”，也不执行自动重连。
- Web Bluetooth 设备选择器不支持 RSSI 阈值过滤，因此不以信号强度作为连接前置条件。

## 验证

- 检查设备请求选项、旧设备记录过滤和连接前名称校验。
- 确认 `JDY-31-SPP`、`JDY-33` 等设备能够进入流程，其他名称被拒绝。
- 保持现有 FFE0/FFE1 通信、参数读取和自动重连逻辑不变。
